// kalau Play Protect memblokir saat dipasang

    
    
      
  • [!]Jangan pasang dari pengelola arsip (ZArchiver dkk). Pakai app Files bawaan HP, atau ketuk notifikasi unduhan dari browser. Pengelola arsip meneruskan berkasnya dengan cara yang sering membuat installer berputar tanpa pesan.
    • 
      
  • [!]Muncul “Aplikasi tidak terpasang”? Itu pesan gagal yang paling umum, dan sebabnya salah satu dari lima ini — periksa urut: (1) sudah ada app bernama Toolbox di daftar aplikasi? uninstall dulu; (2) HP-nya harus Android 8 ke atas (Android 7 ke bawah gagal dengan pesan ini, tanpa menjelaskan); (3) ruang penyimpanan tersisa minimal 50 MB; (4) ukuran berkasnya harus persis seperti angka di baris sha256 di atas; (5) pasang dari app Files atau notifikasi browser, bukan pengelola arsip. Kalau kelimanya sudah, kirim adb install ke admin — pesan aslinya akan menyebut kode INSTALL_FAILED_… dan itu menunjuk sebabnya persis.
    • 
      
  • [!]Muncul “Aplikasi diblokir untuk melindungi perangkat Anda”? Itu Play Protect, bukan APK-nya rusak. APK mod selalu ditandai karena Google belum mengenalnya.
    • 
      
  • [1]Buka Play Store → foto profil kanan atas → Play Protect → ikon gerigi → matikan “Pindai aplikasi dengan Play Protect”.
    • 
      
  • [2]Pasang lagi APK-nya. Kalau masih muncul, pilih “Detail” lalu “Tetap pasang” kalau tombolnya ada.
    • 
      
  • [3]Setelah terpasang, nyalakan kembali Play Protect kalau mau — tidak memengaruhi app.
    • 
      
  • [+]Kalau Play Protect tidak bisa dimatikan (sebagian HP Xiaomi/Realme/Infinix mengunci menunya): pasang lewat adb install dari laptop, atau lewat file manager pihak ketiga setelah izin “Instal aplikasi tidak dikenal” diberikan ke app itu.

// yang perlu kamu tahu

    
    
      
  • [+]Android 8 ke atas, arm64. Tanpa root, tanpa virtual space, tanpa Shizuku, tanpa VPN.
    • 
      
  • [+]Butuh Free Fire build yang memuat modul Assembly-CSharp 0.86.0.518. Kalau modulnya tidak ada, app bilang “modul tidak tersedia” — bukan diam-diam gagal.
    • 
      
  • [+]Key mengikat ke 1 HP kalau kamu isi Android ID saat checkout. Kosongkan kalau mau bisa dipakai pindah HP.
    • 
      
  • [+]Kalau pakai Magisk: aktifkan DenyList untuk com.dts.freefireth, dan sembunyikan nama app Magisk.
    • 
      
  • [+]MATIKAN atau tutup app: modul dihapus, izin folder dilepas, HP kembali seperti semula. Default auto-bersih ON — tidak ada sisa yang menggantung. (Tahan tombol AKTIFKAN untuk bersih total, termasuk key.)
    • 
      
  • [+]Setelan panel tersimpan di HP: pasang sekali, sesi berikutnya dipasang ulang otomatis begitu game dibuka.
    • 
      
  • [–]Tidak ada yang namanya “undetectable”. Yang bisa dijanjikan: tidak ada file dengan hash yang sama di dua HP, dan tidak ada kode kita di dalam APK game.
